# jpfly — самые дешёвые даты для поездки в Японию

Берёт календарь цен Google Flights и для каждого дня вылета и каждой длины поездки (напр. 14–21 день)
находит самую дешёвую цену туда-обратно в любой аэропорт Японии из нескольких домашних аэропортов
(с учётом стоимости доехать до них). Показывает календарь цен и топ вариантов, цены в злотых.

**Отчёт:** https://vladbond2k.github.io/swallow-radio/ — обновляется каждый день и по кнопке
Actions → Search flights → Run workflow (~2–5 минут).

**Настройки** — `config.toml` (окно дат, длина поездки, аэропорты, валюта). Можно править прямо на GitHub.

## Локально

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -e .
jpfly            # → out/index.html
jpfly --demo     # выдуманные цены, без сети
```

Данные — через [fli](https://github.com/punitarani/fli) (неофициальный клиент Google Flights).
Цены — минимальные «от» из календаря; точный рейс и цену смотри по ссылке перед покупкой.
